## Olá! Eu sou o Kauan!

Sou apaixonado pela área de tecnologia. Atualmente estudante de Análise e Desenvolvimento de Sistemas na Fatec Rio Preto e técnico em Desenvolvimento de Sistemas pela ETEC Rio Preto. 

Tenho experiências na área de desenvolvimento web, onde tive a oportunidade de desenvolver o projeto Phila Connection. Esse projeto surgiu como a proposta de conectar os estudantes da Etec Rio Preto com o mercado de trabalho. Tendo participação desde conceitos de Engenharia de Software: levantamento de requisitos, diagramação UML, prototipação e documentação e, na aplicação prática com as tecnologias: Figma, Git & GitHub, HTML & CSS, Javascript, PHP, MySQL.  

Além do desenvolvimento de uma aplicação front-end para empresa Art Parquet, com o objetivo divulgar seus produtos. Esse projeto também envolveu o planejamento e a utilização de tecnologias como Figma, HTML & CSS, Javascript para alavancar os seus negócios.
